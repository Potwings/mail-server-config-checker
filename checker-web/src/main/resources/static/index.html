Mail Health Check

발급된 주소로 점검할 메일 서버에서 테스트 메일을 1통 보내면, 실제 SMTP 세션의 접속 IP · HELO · MAIL FROM을 기준으로 발송 환경을 자동 진단합니다.

  1. 테스트 주소 발급 — 일회용 수신 주소를 발급받습니다. 회원가입도, 도메인 입력도 필요 없습니다.
  2. 테스트 메일 발송 — 점검할 메일 서버를 거쳐 발급 주소로 메일 1통을 보냅니다.
  3. 자동 진단 결과 — 메일이 도착하면 항목별 진단과 개선 가이드가 자동으로 표시됩니다.

테스트 메일은 어떻게 보내나요?
반드시 점검하려는 메일 서버를 거쳐 발송해야 합니다. 개인 Gmail 등 다른 서비스에서 보내면 그 서비스가 진단 대상이 됩니다.
  • 서버 셸에서 직접: echo "health check" | mail -s "test" 발급주소
  • 해당 서버를 SMTP 발신 서버로 쓰는 웹메일 · Outlook 등에서 보내도 됩니다.
